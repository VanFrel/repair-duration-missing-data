# Прогнозирование длительности ремонта в сервисной сети автопроизводителя в условиях неполных данных

### Аннотация
Рассмотрена задача прогнозирования длительности технического обслуживания и ремонта автомобилей в дилерской сети. Исследован массив из 50 000 заказ-нарядов, в котором у 26,4 % записей нет времени предварительной диагностики. Показано, что пропуски неслучайны (MNAR) и связаны с регламентом работ, ведь кузовные повреждения мастер оценивает визуально, без диагностического стенда. Сравнены два способа заполнения пропусков — средним значением и регрессионной импутацией. По 100 случайным разбиениям выборки регрессионная импутация повышает коэффициент детерминации прогноза с 0,898 до 0,923. Полученная точность позволяет называть клиенту срок готовности автомобиля с точностью до часа и заранее предлагать компенсационный сервис при длительных ремонтах.
